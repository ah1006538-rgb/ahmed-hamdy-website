How It's Built

RULES, NOT VIBES

Content work follows the same discipline every time — these are the actual working rules, not a theory page.

Bilingual By Default

Arabic Register Is A Decision

Semi-formal Arabic (light فصحى, never stiff) for clinical/medical accounts; casual عامية where the brand voice calls for it. The register is chosen per account, not copy-pasted.

Hook First

The First Line Does The Work

Every caption and script is written hook-first — the line that earns the next three seconds — before the rest of the copy is built around it.

Structured Calendars

Every Post Has Four Fields

Post type, designer brief, hook, and caption — filled in for every post before it goes to design, so nothing gets improvised at the last minute.

Format Innovation

Borrow The Format, Not The Joke

Recurring cultural formats (a mock "official announcement" style, a recognizable meme structure) get reused as bilingual hook templates — reskinned for the brand, never a straight repost.

Representative Work · In-House, Not A Client File

REAL CREATIVE, NO CLIENT SECRETS

These are real, shipped social creatives — built for Ahmed's own agency brand (Panda Medical), not a client account, and shown here for exactly that reason: no third-party confidentiality applies. Client-specific content and copywriting work exists but is withheld from public display to protect active confidentiality agreements.
